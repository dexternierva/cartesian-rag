# NothingMatches

What to show when the engine returns `state: "no_results"`. It is never a dead end.

- Say plainly that nothing matches **all** the requirements.
- Name the one requirement that, if relaxed, gives results, and what that would show.
- Offer that as a **secondary** (`lantern`) button the shopper can tap, which re-asks without that requirement.
- Uses `status-warn-soft`: this is a caution, not an error.
