# AnswerFact

A single-number answer from a lookup ("How many…", "What does … cost"). The number is large in `display`; the sentence under it says what the number is about: product, colour and place. Never a bare "Available: 48".

- The consumer provides the number, the subject (from the ticket's row: product, depot) and the citation.
- Every number in the sentence must come from a cited field.
